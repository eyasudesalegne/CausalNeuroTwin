# Future held-out predictive validation
Implemented methods are not completed prediction experiments. All scientific execution needs separate approval.

Compare one uncertainty factor at a time: original/reviewed/unresolved-source bounds; original/reviewed/flagged-parcel mapping; pass/endpoint/common-edge and existing structural nulls. Preserve complete neural node order. Do not automatically accept geodesic completion, treat endpoint connectivity as ground truth, recover motion-free connectivity by relabeling, or use fit improvement as anatomical acceptance.

Hold subject, neuronal model, integration, stimulation, verified forward asset, reference, channels, time windows and calibration/search budgets consistent. Keep primary reference-scale network normalization explicit; any secondary coupling or delay adjustment gets equal budgets and separate reporting. Avoid an unbounded Cartesian sweep.

Freeze verified run/session/condition splits before evaluation. All trials from a run remain together. Prefer session-held-out tests where replication permits; state session-condition confounding or insufficient independent recordings. Training controls scaling/nuisance transforms; validation selects prespecified options; held-out test data never select masks, networks, coil poses, windows or hyperparameters.

Use matched waveform error after physical amplitude calibration, temporal correlation, scalp-topography correlation, prespecified latency rules, paired improvement over simple/training-only and structural controls, and descriptive run/session uncertainty. Few sessions do not establish population validity.

Define artifact-safe windows from actual acquisition evidence. Account for pulse/amplifier recovery, muscle, auditory/somatosensory responses, ocular contamination and preprocessing/reference effects. Use sensory/sham controls only if they actually exist.

Experimental C-B60 pose, coordinate transform and dose uncertainty are a separate block. A compatible coil file and study-level target do not establish an individual measured pose. Preserve the frozen Cool-B70 demonstration. No new field, EEG fit or automatic parameter search is included here.
